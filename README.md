# EASY CAR WASH

Үйлчлүүлэгчийн сайт, хамгаалалттай веб админ, Expo админ апп. Бүгд нэг Supabase өгөгдлийн санг ашиглана. Сайт Vercel дээр `dist/` хавтсаас нийтлэгдэнэ.

## Ажиллуулах дараалал

1. Supabase project үүсгэнэ. **SQL Editor** дотор [`supabase/schema.sql`](supabase/schema.sql) файлыг ажиллуулна.
2. Supabase **Authentication → Users** хэсэгт эзний имэйл, нууц үгтэй хэрэглэгч үүсгэнэ. SQL Editor дотор `insert into public.admin_users(user_id) select id from auth.users where email = 'OWNER_EMAIL';` ажиллуулна (`OWNER_EMAIL`-ийг эзний имэйлээр солино).
3. **Project Settings → API** хэсгээс project URL болон **publishable/anon key**-г авна. PowerShell дээр `./scripts/connect-supabase.ps1` ажиллуулаад эдгээр хоёр утгыг оруулна. Скрипт сайт болон Expo аппын тохиргоог хамтад нь бэлдэнэ. **service_role/secret key-г хэзээ ч оруулахгүй**.
4. `git add dist/config.js && git commit -m "Connect Supabase" && git push` хийсний дараа Vercel дахин deploy хийнэ. `admin-app/.env.local` Git-д орохгүй; Expo аппын local тохиргоонд ашиглагдана. Сайт дээр бодит захиалга, админ веб дээр тухайн захиалга харагдахыг шалгана.
5. Expo апп: `cd admin-app`, `npm install`, `npx expo start`. Утсанд туршихдаа Expo Go эсвэл development build ашиглана. App Store/Play Store-д нийтлэхэд Expo/EAS эрх болон signing хэрэгтэй.

### Цагийн хязгааргүй захиалга

Өмнөх 09:00–18:00 хязгаарыг арилгахын тулд одоо ашиглаж байгаа Supabase project-ийн **SQL Editor** дээр [`supabase/migrations/20261029_open_hours.sql`](supabase/migrations/20261029_open_hours.sql)-ийг нэг удаа ажиллуулна. Үүний дараа сайт өгөгдлийн сангаас ирсэн 00:00–23:00 цагийн сонголтыг харуулна. Өнгөрсөн цаг болон нэг цагт хоёр захиалга дүүрсэн үе хаалттай хэвээр байна; бүтэн угаалга хоёр цаг эзэлнэ. SQL-г ажиллуулах хүртэл хуучин 09:00–18:00 цаг л харагдана.

## Захиалгын урсгал

- Үйлчлүүлэгч өдөр, цаг, хаяг, машинаа сонгоно. SQL функц нэг цагийн хоёр хүний багтаамжийг transaction lock ашиглан давхардахаас хамгаална.
- Амжилттай илгээсний дараа `order.html?token=...` хувийн холбоос гарна. Үйлчлүүлэгч энэ холбоосоор төлөв, үнийн санал, мессежээ харж үнийг зөвшөөрч эсвэл татгалзана.
- Админ имэйл, нууц үгээр нэвтэрнэ. Зөвхөн `admin_users` жагсаалтад байгаа хэрэглэгч захиалга харах, засах эрхтэй.
- Веб админ нээлттэй үед шинэ захиалгыг 15 секунд тутам шалгаж хөтчийн мэдэгдэл үзүүлнэ. Expo апп нээлттэй үед 15 секунд тутам шалгаж локал мэдэгдэл үзүүлнэ. **Апп хаалттай үед push мэдэгдэл одоогоор ажиллахгүй**; үүнд Expo push token бүртгэл, FCM/APNs болон серверээс илгээх Edge Function тусад нь тохируулах хэрэгтэй.

## Хязгаарлалт

- Supabase project ба түлхүүрийг эзэн нь үүсгэж холбоогүй бол захиалга илгээх товч идэвхгүй. Хуурамч захиалга хадгалахгүй.
- Нийтийн захиалгын endpoint-ийг production орчинд bot/spam-аас хамгаалахын тулд Captcha эсвэл edge rate limit нэмэх нь зүйтэй.
- Байршил нь хэрэглэгч зөвшөөрсөн үед л авна. Хаяг заавал оруулах шаардлагатай.
